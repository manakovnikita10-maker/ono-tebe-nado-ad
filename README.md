# Оно тебе надо

Учебная страница аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/manakovnikita10-maker/ono-tebe-nado-ad

## Запуск

Открыть `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Что использовано

- Семантические теги HTML: `header`, `nav`, `main`, `section`, `article`, `address`, `footer`.
- Grid для сетки шапки, раздела об аукционе и подвала.
- Flexbox для меню, карточек, контактов и социальных ссылок.
- Локальные шрифты Raleway и изображения из стартового проекта.
- Общий полупрозрачный оверлей для обложки и карточек.

Страница рассчитана на ширину 1100 px, как предусмотрено стартовой заготовкой.
